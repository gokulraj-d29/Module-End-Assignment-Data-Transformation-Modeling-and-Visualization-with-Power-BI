📊 Data Transformation, Modeling and Visualization with Power BI
Project Overview

This project was completed as part of the Module End Assignment: Data Transformation, Modeling, and Visualization with Power BI. The objective of this project is to demonstrate the complete data analytics workflow, including data cleaning, transformation, data modeling, DAX calculations, and dashboard creation using Power BI.

The project converts raw data into meaningful insights through interactive visualizations and analytical reporting, enabling informed decision-making.

Project Objectives
Perform data cleaning and preprocessing using Power BI Query Editor.
Transform raw data into a structured format suitable for analysis.
Create relationships and build an optimized data model.
Develop DAX measures and calculated columns for advanced analysis.
Design an interactive and user-friendly dashboard.
Generate meaningful business insights from the dataset.

DAX Measures Created

Examples of DAX calculations used in this project:

Total Sales = SUM(Sales[Sales Amount])

Average Sales = AVERAGE(Sales[Sales Amount])

Total Profit = SUM(Sales[Profit])

Profit Margin % =
